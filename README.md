# HR Analytics Tableau Dashboard

An interactive Tableau HR Analytics Dashboard designed to transform raw employee data into actionable workforce insights. This project helps organizations analyze employee attrition, department trends, job roles, demographics, and key HR performance indicators through a clean, executive-ready visual experience.

## Author

* **Omkar Pardeshi**

## Project Overview

HR teams frequently manage large volumes of employee data across multiple attributes—such as overall workforce count, turnover, compensation, department structures, education levels, and job titles. Without proper visualization tools, raw datasets make it difficult to pinpoint where turnover is happening or identify specific workforce segments requiring retention strategies.

The goal of this project was to construct an intuitive, interactive Tableau dashboard that enables HR leaders to rapidly analyze attrition patterns, evaluate department-level metrics, and drive data-informed retention planning.

## Key Features & Highlights

* **Core HR Metrics Summary**: Top-level KPI cards displaying total employee count, attrition count, attrition rate, average age, and average salary for rapid executive reviews.
* **Interactive Filtering & Exploration**: Dynamic multi-attribute filters allowing users to slice data by:
  * Department & Job Role
  * Gender & Age Group
  * Education Field & Salary Bracket
* **Turnover & Attrition Analysis**: Visual charts designed to isolate high-turnover segments and compare attrition rates across different departments and demographics.
* **Executive-Ready Layout**: Clean, structured dashboard flow following a "Summary to Detail" visual hierarchy.

## Project Details

* **Tool / Technology:** Tableau
* **Project Type:** Open Source
* **Development Duration:** 2 Days
* **Reach / Impact:** Reached 30+ users within 30 days

## Technical Implementation

1. **Calculated Fields**: Formulated dynamic measures to produce key metric indicators like Attrition Rate and custom demographic segmentations.
2. **Dashboard Architecture**: Consolidated multiple workforce dimensions into a single unified layout to avoid visual clutter while maximizing insight depth.
3. **Exploratory Drill-Downs**: Enabled interactive cross-filtering across visual charts to allow stakeholders to perform self-service analysis.

## Getting Started / How to View

1. **Tableau Public / Desktop**: Open the workbook using [Tableau Desktop](https://www.tableau.com/products/desktop) or [Tableau Reader](https://www.tableau.com/products/reader).
2. **Interact with Filters**: Use the global filters on the dashboard panel to adjust department, gender, and job role parameters to explore localized workforce insights.
